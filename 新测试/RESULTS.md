# 固定测试集实验结果

目标为两条路线在原有固定测试集上达到 98% 准确率。本轮最佳 TF-IDF 方案为 **95.21%**，最佳 Transformer 方案为 **96.51%**，分别距目标 **2.79** 和 **1.49** 个百分点。

| 方案 | Dev 准确率 | 测试准确率 | 测试 Macro-F1 | 正确条数 |
| --- | ---: | ---: | ---: | ---: |
| 原 TF-IDF + LinearSVC 基线 | 94.62% | 94.74% | 93.94% | |
| TF-IDF + LinearSVC，加入标题首尾、格式和训练集相似标题检索 | 95.22% | **95.21%** | 94.46% | 68,382 |
| 原 Transformer Tiny 基线 | 91.24% | 91.29% | 89.87% | |
| MacBERT-base，第 3 轮 | 96.32% | 96.44% | 95.94% | 69,268 |
| MacBERT-base，第 3 轮，加入训练集相似标题检索 | 96.41% | **96.51%** | 96.06% | 69,321 |

固定测试集有 71,826 条，98% 至少需答对 70,390 条。两条最佳路线分别还差 2,008 和 1,069 条。原 Transformer Tiny 的七轮调参版本曾达到 94.01% 测试准确率，作为另一历史对照。

TF-IDF 先测试字符 1–4 gram、数字与空白归一化和训练集检索，Dev 准确率为 94.88%。单独训练常见混淆类别对的二分类器只额外正确 4 条 Dev 样本。最终按 Dev 分数选用包含标题首尾、格式特征的方案。测试集上，「股票」与「科技」双向错分 515 条。 

MacBERT-base 从公开中文预训练权重初始化，在 646,510 条标题上微调 3 轮。完整轮次的 Dev 准确率分别为 95.57%、96.06%、96.32%。比较了末两轮权重的 50% / 50% 与 25% / 75% 加权平均，两种平均权重的 Dev 均低于第 3 轮单独权重。最终检索加权强度及最低相似度均依据 Dev 选择。检索对照在测试集多答对 53 条。[MacBERT 权重来源](https://huggingface.co/hfl/chinese-macbert-base/tree/a986e004d2a7f2a1c2f5a3edef4e20604a974ed1)

三个测试报告均核对了 71,826 条标题的顺序，使用与原报告一致的标签文件 SHA-256。训练和验证各使用原固定数据，测试标签由评分脚本读取。本项目新增文件全部位于「新测试」，对目录外 4,846 个原项目文件核对了路径、大小和修改时间，差异为零。
