# 原基线上的算法优化实验

本目录保存基于原项目开展的超参数和模型优化代码、训练产物、预测及评估报告。数据沿用仓库 `database/` 中处理后的固定划分。所有结果为本地固定划分成绩。

## 数据与评估

| 阶段 | 文件 | 数量 |
| --- | --- | ---: |
| 训练与拟合词表 | `../database/train.txt` | 646,510 |
| 验证与选择参数、检查点 | `../database/dev.txt` | 68,736 |
| 测试预测 | `../database/test.txt` | 71,826 |
| 预测后的独立评分 | `../database/test_labeled.txt` | 71,826 |

三组标题按原文完全匹配时交集为零，近似标题仍可能跨集合出现。`verify_split.py` 和 `split_audit.json` 保存划分核对方法及文件哈希。`evaluate_test.py` 在读取标签评分时逐行核对测试标题顺序。

## 对照结果

| 方法 | Dev Accuracy | Dev Macro-F1 | Test Accuracy | Test Macro-F1 |
| --- | ---: | ---: | ---: | ---: |
| 原 TF-IDF + LinearSVC | 94.62% | 93.73% | 94.74% | 93.94% |
| 改进 TF-IDF + LinearSVC | 95.22% | 94.45% | 95.21% | 94.46% |
| 原 Transformer Tiny | 91.24% | 89.64% | 91.29% | 89.87% |
| MacBERT-base | 96.32% | 95.77% | 96.44% | 95.94% |
| MacBERT-base 加训练集检索 | 96.41% | 95.85% | 96.51% | 96.06% |

相对最初对应基线，改进 TF-IDF 的测试 Accuracy 提升约 0.46 个百分点，单独 MacBERT 提升约 5.15 个百分点，MacBERT 加检索提升约 5.22 个百分点。98% 的目标准确率尚未达到。MacBERT 替换同时改变了模型规模、预训练权重和微调配置，上表无法单独归因每项变化。

## TF-IDF 与线性 SVM 的改进

最终方案融合三个模型。原样字符模型采用字符 1–3 gram，归一化模型统一全半角、大小写、数字串和空白后采用字符 1–4 gram，首尾与格式模型额外提取标题边界、字符类型模式、长度区间和空白数量。各自的词表和 IDF 均在训练集拟合。

对每类，先计算 `0.75 × 原样模型分数 + 0.25 × 归一化模型分数 + 0.7 × max(相似度 − 0.35, 0)`。最终以该分数的 25% 与首尾格式模型分数的 75% 融合，取最高分类别。配置由 Dev 选择。

- `tfidf_retrieval.py` 训练归一化 SVM、建立检索索引，并与复制的 `baseline_svm.joblib` 融合。
- `tfidf_position.py` 训练并融合首尾与格式模型，最终测试报告位于 `outputs/tfidf_position/test_metrics.json`。
- `tfidf_pairwise.py` 对常见混淆类别训练二分类器作对照，该对照没有进入最终首尾格式方案。

首尾和格式特征在本实验中联合加入，各自的独立贡献还需要单独消融。

## Transformer 的改进

用 12 层、768 维的 MacBERT-base 替换 2 层、128 维的 Tiny。加载公开中文预训练权重，在训练标题上微调整个编码器及 14 类分类头。使用 64 词元上限、batch size 128、峰值学习率 `4e-5`、AdamW、6.5% 预热和余弦衰减，训练 3 轮，以 Dev Accuracy 选择最佳检查点。按长度分桶和 BF16 用于提高运行效率。

`train_macbert.py` 为训练及预测入口，`outputs/macbert/model/` 为最佳模型，`last_checkpoint.pt` 保存最近完整轮次和优化器状态。完整轮次 Dev Accuracy 分别为 95.57%、96.06%、96.32%。`macbert_average.py` 另比较第 2、3 轮权重平均，两种平均方案均未超过第 3 轮单独权重。预训练模型来源为 [hfl/chinese-macbert-base](https://huggingface.co/hfl/chinese-macbert-base/tree/a986e004d2a7f2a1c2f5a3edef4e20604a974ed1)。

## 训练集检索

索引只使用训练标题及标签，采用归一化字符 TF-IDF，保留训练文档频次在 3–1,800 之间、长度至少为 2 的片段。L2 归一化向量的内积对应余弦相似度，每类取最高相似度。

MacBERT 检索方案对每类计算 `logit + 4 × max(相似度 − 0.35, 0)`。加分系数和阈值按 Dev 选择。固定测试上相对纯 MacBERT 改对 127 条、改错 74 条，另有 9 条改变后仍错，净增加 53 条正确预测。相近措辞但栏目不同的标题可能导致误导，跨时间、跨来源的鲁棒性还未验证。

## 下载与复现

本目录的大型模型、检查点和二进制数组由 Git LFS 管理。克隆后需要下载 LFS 实体文件，Python 才能加载模型。GitHub 页面显示的 LFS 指针需要通过 Git LFS 拉取。

```powershell
git lfs install
git clone https://github.com/Luxorion-12/NewsClassification-Paddle-Competition.git
cd NewsClassification-Paddle-Competition
git lfs pull --include="新测试/**"
cd 新测试
```

复现环境可在自己的 Python 虚拟环境中安装以下依赖。PyTorch 需选择与 GPU、驱动兼容的版本，本次 GPU 实验使用 PyTorch 2.8.0+cu126。

```powershell
python -m pip install transformers==4.46.3 scikit-learn==1.7.2 scipy==1.15.3 joblib safetensors
```

`README.md` 保留本机已有环境路径和训练命令。换机器时，把解释器改为已安装依赖的 `python`，并去掉指向本机 `gpu_packages` 的 `PYTHONPATH` 设置。数据目录默认指向同仓库的 `../database`。在安装好依赖的环境中，可以从保存模型重新预测并评分。

```powershell
$env:PYTHONDONTWRITEBYTECODE = '1'
$env:HF_HUB_OFFLINE = '1'
$env:TRANSFORMERS_OFFLINE = '1'
$env:HF_HOME = Join-Path $PWD 'cache'
python -X utf8 verify_split.py
python -X utf8 tfidf_position.py --predict-only
python -X utf8 train_macbert.py --predict-only
python -X utf8 macbert_retrieval.py
python -X utf8 evaluate_test.py --data-dir ../database --predictions outputs/tfidf_position/predictions.txt
python -X utf8 evaluate_test.py --data-dir ../database --predictions outputs/macbert/predictions.txt
python -X utf8 evaluate_test.py --data-dir ../database --predictions outputs/macbert_retrieval/predictions.txt
```

BF16 训练使用支持 BF16 的 CUDA GPU。现有日志包括权重平均快照过程的一次非连续张量保存失败，代码修复后已成功保存 `outputs/macbert_average/epoch2.safetensors`。`source_before.txt` 与 `source_check.txt` 是当时本地源文件核对记录。

更多逐项指标和混淆矩阵见各输出目录中的 `metrics.json` 与 `test_metrics.json`，汇总见 [RESULTS.md](RESULTS.md)。
