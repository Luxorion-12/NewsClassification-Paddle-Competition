# 数据集说明

## 来源与内容

比赛的[赛题定义页](https://aistudio.baidu.com/competition/detail/809/0/task-definition)说明该任务基于 THUCNews。页面介绍称，THUCNews 根据新浪新闻 RSS 频道 2005 至 2011 年间的历史数据筛选整理，包含约 74 万篇新闻文档。

本比赛的任务是依据新闻标题预测类别。比赛页面列出的类别为：

财经、彩票、房产、股票、家居、教育、科技、社会、时尚、时政、体育、星座、游戏、娱乐。

## 获取数据

请从[比赛官方页面](https://aistudio.baidu.com/competition/detail/809/0/introduction)进入赛事数据区，按平台要求登录并获取本届比赛提供的文件。若数据区未显示，请查看[赛题定义](https://aistudio.baidu.com/competition/detail/809/0/task-definition)及[相关学习资料](https://aistudio.baidu.com/competition/detail/809/0/related-material)。

官方页面可能要求登录。实际训练集、测试集的文件名、行数、字段顺序、分隔符和标签编码，应以从官方平台取得的数据包为准；目前公开介绍未提供足够信息来可靠固定这些细节。

## 关于本仓库

本仓库不包含比赛原始数据文件。公开页面未明确授予将数据复制并再发布到 GitHub 的许可，因此此处仅提供数据概述和官方入口。下载、使用或分享数据前，请查看 AI Studio 与数据集页面当时适用的条款。
