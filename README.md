## 数据集

比赛页面将任务描述为基于 THUCNews 的新闻标题分类。由于目前公开页面没有明确说明数据文件的再分发许可，本仓库只记录数据集说明和官方获取入口，不托管比赛原始数据。请通过 AI Studio 官方页面获取数据，并遵守平台与数据集的适用条款。
